## Сверка ⚠-расхождений с официальными первоисточниками (после источника 77, по решению пользователя — сбор источников приостановлен на 75/156, приоритет переключён на разрешение открытых вопросов)

Все 4 висевших ⚠-расхождения сверены напрямую с официальными Go-материалами (актуальный исходный код рантайма на `raw.githubusercontent.com/golang/go/master`, официальные release notes `go.dev/doc/go1.24`, историческое обсуждение разработчиков Go по GC), а не с ещё одним пересказом от очередного интервью-источника — это качественно более надёжный уровень подтверждения, чем обычная сверка между интервью-источниками. Результаты:

1. **Рост ёмкости слайса** (файл 04) — закрыто. Актуальный `runtime/slice.go` подтверждает: порог **256**, удвоение ниже порога, `newcap += (newcap + 3×256) >> 2` (≈×1.25) выше порога — дословно так и написано в комментарии исходника. Версия «256/×1.25» оказалась точной, «~×2/~×1.5 без точного числа» — грубым, но не ошибочным пересказом, «1024/+25%» — просто неверной (неверный порог).
2. **Внутреннее устройство map: бакеты vs open addressing** (файл 04) — закрыто, и результат интереснее, чем ожидалось: это не конфликт версий, а два **реальных** периода жизни рантайма. Go 1.24 (февраль 2025) официально перевёл `map` на реализацию по мотивам Swiss Tables (open addressing) — подтверждено дословной цитатой из release notes. Версия A (бакеты+tophash) верна для Go ≤1.23, версия B (open addressing+SIMD+tombstones) верна для Go ≥1.24.
3. **Честность `sync.Mutex`: spinning/starvation** (файл 08) — закрыто и подтверждено дословно по исходнику `internal/sync/mutex.go` (куда в Go 1.24 вынесена реализация): нормальный режим explicitly не FIFO по владению («competes with new arriving goroutines»), порог перехода в starvation mode — именованная константа `starvationThresholdNs = 1e6` (ровно 1 мс, как и стояло в конспекте), starvation mode — строгий handoff без обгона. Заодно подтверждено, что Go 1.24 попутно ввёл новую реализацию этого мьютекса рантайма (не меняющую описанную семантику).
4. **Ориентир по STW-паузам GC: <10 мс vs <100 мкс** (файл 08) — закрыто. Обе цифры реальны и относятся к разным эпохам: <10 мс — историческая цель до Go 1.8 (до февраля 2017), <100 мкс — официально объявленная и достигнутая цель начиная с Go 1.8 (объявление Austin Clements, октябрь 2016) и остающаяся актуальной по сей день. Дословная цитата из обсуждения: «typical worst-case stop-the-world times less than 100 microseconds».

Все четыре правки внесены в файлы 04/08 текстом, заменяющим прежние формулировки «требует проверки» на подтверждённый факт с явной пометкой источника проверки (не из общей нумерации `_istochniki.md`, а прямая ссылка на официальный материал). Единственная деталь, оставшаяся открытой намеренно — порог пересборки новой (Swiss Tables) реализации map при ~20% удалённых записей (заявлен кандидатом на одном из собеседований, официальными материалами Go не детализирован ни в подтверждение, ни в опровержение) — оставлен как явно помеченная неподтверждённая деталь, а не факт.
