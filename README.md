# Стек знаний

Личная база подготовки к техническим собеседованиям.

- `index.html` — главная страница со списком модулей (языки, БД, CS, инструменты).
- `go-notes.html` — конспект по Go: 15 глав + флеш-карты для самопроверки (147 вопросов).
- `careerclue.vercel.app/` — исходные markdown-заметки и вопросы/ответы по Go, из которых собран конспект.

Обе HTML-страницы самодостаточны — открываются просто двойным кликом / в браузере, без сборки.
