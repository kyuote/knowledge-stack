Глава 03

Коллекции

Collections Framework — основа Java. На собесе спрашивают реализации, сложность операций и разницу между ними. Надо знать как таблицу умножения.

3.1List: ArrayList vs LinkedList

ArrayList — динамический массив. LinkedList — двусвязный список. На практике ArrayList быстрее почти всегда — лучше кэш-локальность.

ListDemo.java
List<String> list = new ArrayList<>();
list.add("a");
list.add("b");
list.add(0, "z");   // вставка в начало — O(n), сдвигает остальные
list.get(1);        // O(1) — прямой доступ по индексу
list.remove(0);     // O(n) — сдвиг
list.size();        // 2
list.contains("b"); // O(n)

// Неизменяемый список (Java 9+)
List<String> immutable = List.of("a", "b", "c");

// Сортировка
Collections.sort(list);
list.sort(Comparator.naturalOrder());
list.sort(Comparator.reverseOrder());
list.sort(Comparator.comparing(String::length));
ArrayList: внутреннее устройство детали

Внутри — обычный Object[]. При добавлении элемента сверх capacity создаётся новый массив размером capacity * 1.5 и данные копируются. Начальный capacity = 10.

Если заранее известен размер — передай его в конструктор: new ArrayList<>(1000) — избежишь лишних копирований.

3.2Map: HashMap, LinkedHashMap, TreeMap

MapDemo.java
// HashMap — хэш-таблица, порядок не гарантирован, O(1) get/put
Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.put("b", 2);
map.get("a");           // 1
map.getOrDefault("z", 0);  // 0
map.containsKey("b");   // true
map.putIfAbsent("a", 99);  // не перезапишет, т.к. "a" уже есть

// Итерация
for (var entry : map.entrySet()) {
    System.out.println(entry.getKey() + "=" + entry.getValue());
}

// LinkedHashMap — сохраняет порядок вставки, O(1) get/put
Map<String, Integer> linked = new LinkedHashMap<>();

// TreeMap — сортировка по ключу (Comparable или Comparator), O(log n)
Map<String, Integer> tree = new TreeMap<>();
tree.firstKey();    // наименьший ключ
tree.lastKey();     // наибольший ключ

// Неизменяемый map (Java 9+)
Map<String, Integer> im = Map.of("a", 1, "b", 2);
HashMap: внутреннее устройство детали

HashMap — массив «бакетов» (buckets). Ключ хэшируется → hash % capacity → индекс бакета. Коллизии разрешаются цепочкой (linked list). При длине цепочки > 8 — превращается в красно-чёрное дерево (Java 8+), O(log n) в худшем случае.

Load factor = 0.75 по умолчанию. При заполнении > 75% — resize: capacity × 2, rehash всех элементов. Если знаешь размер заранее: new HashMap<>(expectedSize * 4 / 3 + 1).

Ключи в HashMap должны переопределять equals и hashCode. Если hashCode меняется после вставки — элемент потеряется.

3.3Set: HashSet, TreeSet

Set не допускает дубликатов. HashSet — HashMap под капотом (ключи — элементы, значения — константа). TreeSet — TreeMap под капотом, элементы отсортированы.

SetDemo.java
Set<String> set = new HashSet<>();
set.add("a");
set.add("b");
set.add("a");    // дубликат — не добавится
set.size();      // 2
set.contains("a"); // O(1)

// LinkedHashSet — порядок вставки сохраняется
Set<String> linked = new LinkedHashSet<>();

// TreeSet — сортировка, O(log n)
Set<Integer> tree = new TreeSet<>();
tree.add(3); tree.add(1); tree.add(2);
System.out.println(tree);  // [1, 2, 3]
tree.first();  // 1
tree.last();   // 3
tree.headSet(2); // [1] — всё меньше 2

// Операции над множествами
Set<Integer> a = new HashSet<>(Set.of(1,2,3));
Set<Integer> b = new HashSet<>(Set.of(2,3,4));
a.retainAll(b); // пересечение: {2, 3}
a.addAll(b);    // объединение
a.removeAll(b); // разность

3.4Queue и Deque

Queue — FIFO. Deque (double-ended queue) — и стек, и очередь. ArrayDeque — быстрее Stack и LinkedList для задач стека/очереди.

QueueDemo.java
// Queue (FIFO)
Queue<Integer> q = new ArrayDeque<>();
q.offer(1); q.offer(2); q.offer(3); // добавить в хвост
q.peek();   // 1 — посмотреть голову без удаления
q.poll();   // 1 — извлечь голову

// Deque как стек (LIFO)
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1); stack.push(2); stack.push(3);
stack.peek();  // 3 — вершина
stack.pop();   // 3 — снять с вершины

// PriorityQueue — очередь с приоритетом (min-heap)
PriorityQueue<Integer> pq = new PriorityQueue<>();
pq.offer(5); pq.offer(1); pq.offer(3);
pq.poll();  // 1 — всегда минимальный
// max-heap:
PriorityQueue<Integer> maxPQ = new PriorityQueue<>(Comparator.reverseOrder());
