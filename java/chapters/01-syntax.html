Базовый синтаксис

Примитивы и autoboxing, строки, var, управляющие конструкции, массивы — фундамент, который спрашивают в первые 10 минут собеса.

1.1Примитивы и autoboxing

Java — строго типизированный язык. Есть 8 примитивных типов — они хранятся на стеке и передаются по значению. У каждого есть обёрточный класс (wrapper) в java.lang.

Primitives.java
// Примитивы и их обёртки
byte   b = 127;          // 8 бит,  Byte
short  s = 32_767;       // 16 бит, Short
int    i = 2_147_483_647;// 32 бит, Integer
long   l = 9_223_372L;   // 64 бит, Long  (суффикс L)
float  f = 3.14f;        // 32 бит, Float (суффикс f)
double d = 3.14159265;   // 64 бит, Double
char   c = 'A';          // 16 бит Unicode, Character
boolean flag = true;     // Boolean

// Autoboxing: компилятор сам оборачивает/разворачивает
Integer x = 42;          // autoboxing:   int → Integer
int     y = x;           // unboxing:     Integer → int
Ловушки autoboxing важно
Traps.java
// 1. == сравнивает ссылки, а не значения
Integer a = 1000, b = 1000;
System.out.println(a == b);      // false! (разные объекты)
System.out.println(a.equals(b)); // true

// Integer кэширует значения от -128 до 127
Integer c = 100, d = 100;
System.out.println(c == d);      // true (кэш!)

// 2. NullPointerException при unboxing null
Integer n = null;
int val = n;  // NullPointerException

// 3. Производительность: в тайт-лупе лучше int[], а не Integer[]

1.2String и StringBuilder

String — иммутабельный объект. Каждая операция конкатенации создаёт новый объект в куче. Для изменяемых строк — StringBuilder (не thread-safe) или StringBuffer (thread-safe, медленнее).

Strings.java
String s = "hello";
s.toUpperCase();         // НЕ меняет s — возвращает новый объект
String upper = s.toUpperCase(); // правильно

// Конкатенация в цикле — O(n²)
String bad = "";
for (int i = 0; i < 1000; i++) bad += i; // создаёт 1000 объектов!

// StringBuilder — O(n)
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) sb.append(i);
String good = sb.toString();

// Сравнение строк
String a = "hi", b = new String("hi");
System.out.println(a == b);        // false (разные ссылки)
System.out.println(a.equals(b));   // true  (всегда используй equals)

// String pool: литералы интернируются автоматически
String x = "hi", y = "hi";
System.out.println(x == y);        // true (один объект из пула)
Полезные методы String api
StringAPI.java
String s = "  Hello, World!  ";
s.trim()                    // "Hello, World!" (убирает пробелы)
s.strip()                   // то же, но Unicode-корректно (Java 11)
s.toLowerCase()             // "  hello, world!  "
s.contains("World")         // true
s.startsWith("  Hello")     // true
s.replace("World", "Java")  // "  Hello, Java!  "
s.split(", ")               // ["  Hello", "World!  "]
s.charAt(2)                 // 'H'
s.substring(2, 7)           // "Hello"
s.indexOf("o")              // 4
String.valueOf(42)          // "42"
"42".isBlank()              // false (Java 11)
"  ".isBlank()              // true
String.format("%s=%d", "x", 5) // "x=5"
"hello".repeat(3)           // "hellohellohello" (Java 11)

1.3var и вывод типов

С Java 10 можно использовать var для локальных переменных — компилятор выведет тип сам. Это не динамическая типизация — тип фиксируется на этапе компиляции.

VarDemo.java
// var работает только для локальных переменных с инициализатором
var list = new ArrayList<String>(); // тип: ArrayList<String>
var map  = new HashMap<String, Integer>();
var s    = "hello";   // тип: String

// Нельзя использовать:
// var x;           // без инициализатора — ошибка
// var x = null;    // неоднозначно — ошибка
// class Field { var x = 1; } // поля класса — ошибка

// Удобно с длинными дженерик-типами
var entries = new HashMap<String, List<Integer>>().entrySet();

1.4Операторы и управляющие конструкции

Control.java
// switch-выражение (Java 14+) — возвращает значение
int day = 3;
String name = switch (day) {
    case 1 -> "Пн";
    case 2 -> "Вт";
    case 3 -> "Ср";
    default -> "другой";
};

// switch с yield (для многострочных веток)
int result = switch (day) {
    case 1, 7 -> 0;    // несколько кейсов через запятую
    default -> {
        System.out.println("будни");
        yield day * 2;  // yield вместо return
    }
};

// for-each
int[] arr = {1, 2, 3};
for (int x : arr) System.out.println(x);

// Тернарный оператор
int abs = (x < 0) ? -x : x;

// instanceof с pattern matching (Java 16+)
Object obj = "hello";
if (obj instanceof String str) {
    System.out.println(str.length()); // str уже String, без каста
}

1.5Массивы

Массивы в Java — объекты с фиксированной длиной. Размер нельзя изменить после создания. Для динамических коллекций — ArrayList.

Arrays.java
// Создание
int[] a = new int[5];           // [0, 0, 0, 0, 0]
int[] b = {1, 2, 3, 4, 5};
String[] s = new String[3];     // [null, null, null]
int[][] matrix = new int[3][4]; // 2D-массив

// Работа с java.util.Arrays
import java.util.Arrays;
Arrays.sort(b);                          // сортировка in-place
Arrays.binarySearch(b, 3);              // поиск (только в sorted)
Arrays.fill(a, 7);                       // [7, 7, 7, 7, 7]
int[] copy = Arrays.copyOf(b, 3);       // [1, 2, 3]
int[] range = Arrays.copyOfRange(b,1,4);// [2, 3, 4]
System.out.println(Arrays.toString(b)); // "[1, 2, 3, 4, 5]"
Arrays.equals(a, b);                    // поэлементное сравнение
Для сравнения массивов всегда используй Arrays.equals(a, b), не a.equals(b) и не a == b — оба сравнивают ссылки.
