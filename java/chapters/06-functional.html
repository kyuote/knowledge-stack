Глава 06

Stream API и лямбды

Лямбды, функциональные интерфейсы, Stream pipeline, Optional, Collectors. Появились в Java 8 и стали стандартным стилем написания кода.

6.1Лямбды и функциональные интерфейсы

Лямбда — анонимная функция. Работает там, где ожидается функциональный интерфейс (FI) — интерфейс с ровно одним абстрактным методом (@FunctionalInterface).

Lambda.java
// Основные функциональные интерфейсы из java.util.function
Predicate<String>  p = s -> s.length() > 3;  // T -> boolean
Function<String, Integer> f = String::length;  // T -> R
Supplier<String>   s = () -> "hello";          // () -> T
Consumer<String>   c = System.out::println;    // T -> void
BiFunction<Integer,Integer,Integer> add = (a,b) -> a + b;
UnaryOperator<Integer> dbl = x -> x * 2;      // T -> T

// Применение
p.test("hi");      // false
f.apply("hello");  // 5
s.get();           // "hello"
c.accept("world"); // выводит "world"

// Композиция
Predicate<String> notEmpty = s1 -> !s1.isEmpty();
Predicate<String> longAndNotEmpty = p.and(notEmpty);
Function<String, String> trim = String::trim;
Function<String, Integer> len = String::length;
Function<String, Integer> trimLen = trim.andThen(len); // compose слева направо

6.2Stream: промежуточные и терминальные

Stream — конвейер ленивых операций над последовательностью элементов. Промежуточные операции — ленивые, возвращают Stream. Терминальные — запускают конвейер, возвращают результат.

Streams.java
List<String> names = List.of("Alice", "Bob", "Charlie", "Dave", "Anna");

// Промежуточные: filter, map, flatMap, sorted, distinct, limit, skip, peek
List<String> result = names.stream()
    .filter(n -> n.startsWith("A"))   // Alice, Anna
    .map(String::toUpperCase)          // ALICE, ANNA
    .sorted()                          // ALICE, ANNA
    .toList();                         // Java 16+

// flatMap — разворачивает Stream<Stream<T>> в Stream<T>
List<List<Integer>> nested = List.of(List.of(1,2), List.of(3,4));
List<Integer> flat = nested.stream()
    .flatMap(Collection::stream)  // [1, 2, 3, 4]
    .toList();

// Числовые стримы (избегают autoboxing)
int sum = IntStream.rangeClosed(1, 100).sum(); // 5050
OptionalDouble avg = IntStream.of(1,2,3,4,5).average();

// Параллельный стрим (осторожно — только для CPU-задач без side effects)
long count = names.parallelStream()
    .filter(n -> n.length() > 3)
    .count();
Терминальные операции api
Terminal.java
stream.forEach(System.out::println);  // обход
stream.count();                        // количество
stream.findFirst();                    // Optional<T>
stream.findAny();                      // Optional<T> (быстрее в parallel)
stream.anyMatch(p);                    // boolean
stream.allMatch(p);                    // boolean
stream.noneMatch(p);                   // boolean
stream.min(Comparator.naturalOrder()); // Optional<T>
stream.max(Comparator.naturalOrder()); // Optional<T>
stream.toList();                       // List<T> (Java 16+)
stream.toArray();                      // Object[]

// reduce
int product = IntStream.of(1,2,3,4).reduce(1, (a,b) -> a * b); // 24

6.3Optional

Optional<T> — контейнер, который может содержать значение или быть пустым. Заменяет null в возвращаемых значениях методов — явно сигнализирует, что значение может отсутствовать.

OptionalDemo.java
// Создание
Optional<String> opt = Optional.of("hello");    // NPE если null
Optional<String> safe = Optional.ofNullable(maybeNull);
Optional<String> empty = Optional.empty();

// Получение значения
opt.get();                        // "hello", NoSuchElementException если пуст
opt.orElse("default");            // значение или "default"
opt.orElseGet(() -> compute());   // ленивый fallback
opt.orElseThrow();                // NoSuchElementException если пуст
opt.orElseThrow(() -> new RuntimeException("not found"));

// Проверка и маппинг
opt.isPresent();                  // true
opt.isEmpty();                    // false (Java 11+)
opt.ifPresent(System.out::println); // вызовет println

opt.map(String::length)           // Optional<Integer>(5)
   .filter(n -> n > 3)           // Optional<Integer>(5)
   .orElse(0);                    // 5

// flatMap — когда маппинг возвращает Optional
Optional<String> trimmed = opt.flatMap(s -> s.isBlank() ? Optional.empty() : Optional.of(s.trim()));
Optional — для возвращаемых значений методов, не для полей класса и не для параметров методов.

6.4Method references

MethodRef.java
// 4 вида ссылок на методы:

// 1. Статический метод: Class::staticMethod
Function<String, Integer> parse = Integer::parseInt;
// Эквивалент: s -> Integer.parseInt(s)

// 2. Метод экземпляра на конкретном объекте: obj::method
String prefix = "Hello";
Predicate<String> startsWith = prefix::startsWith;
// Эквивалент: s -> prefix.startsWith(s)

// 3. Метод экземпляра на произвольном объекте: Class::method
Function<String, String> upper = String::toUpperCase;
// Эквивалент: s -> s.toUpperCase()

// 4. Конструктор: Class::new
Supplier<ArrayList<String>> listFactory = ArrayList::new;
// Эквивалент: () -> new ArrayList<String>()

// Применение
List.of("a","b","c").forEach(System.out::println); // тип 2
List.of("a","b","c").stream().map(String::toUpperCase).toList(); // тип 3

6.5Collectors

Collectors.java
import static java.util.stream.Collectors.*;

List<String> words = List.of("apple", "banana", "cherry", "avocado");

// Сбор в коллекции
words.stream().collect(toList());    // List (изменяемый)
words.stream().collect(toSet());
words.stream().collect(toUnmodifiableList());

// joining — склеивание строк
words.stream().collect(joining(", ", "[", "]")); // "[apple, banana, ...]"

// groupingBy — группировка
Map<Character, List<String>> byFirst =
    words.stream().collect(groupingBy(w -> w.charAt(0)));
// {a=[apple, avocado], b=[banana], c=[cherry]}

// counting внутри groupingBy
Map<Character, Long> countByFirst =
    words.stream().collect(groupingBy(w -> w.charAt(0), counting()));

// partitioningBy — разделение на два
Map<Boolean, List<String>> parts =
    words.stream().collect(partitioningBy(w -> w.length() > 5));

// toMap
Map<String, Integer> lengths =
    words.stream().collect(toMap(w -> w, String::length));
